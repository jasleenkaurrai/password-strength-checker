# Project Statement

## Project Title

**Password Strength Checker**

## Problem Statement

Weak passwords can make user accounts more vulnerable to unauthorized access. Many users are not aware of the characteristics of a strong password.

The purpose of this project is to develop a Python-based Password Strength Checker that analyzes a password according to predefined security rules and provides feedback to the user.

## Project Scope

The project focuses on:

* Checking password length
* Checking uppercase letters
* Checking lowercase letters
* Checking numbers
* Checking special characters
* Calculating a password strength score
* Providing suggestions for improvement
* Generating random strong passwords
* Validating user input
* Maintaining password-checking history

The project is designed as a console-based Python application.

## Target Users

The target users are:

* Students
* Beginners learning cybersecurity concepts
* General computer users
* Users who want to understand basic password-strength requirements

## High-Level Features

### 1. Password Strength Analysis

The system evaluates a password using five criteria and assigns a score from 0 to 5.

### 2. Password Generation

The system generates a random password containing different types of characters.

### 3. Input Validation

The system checks for invalid input such as an empty password or spaces.

### 4. History Management

The system stores password-checking results in a text file and allows the user to view the history.

## Expected Outcome

The expected outcome is a simple and modular Python application that helps users understand password-strength requirements and demonstrates practical use of Python programming concepts.
